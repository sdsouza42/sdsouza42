# Hey, I'm Savio.

I'm a software developer based in Vancouver, BC, with a background in business and a Computer Systems Technology diploma from BCIT.

I like building things, figuring out how they work, and occasionally spending far too much time understanding why something behaves the way it does.

My main interests are full-stack web development, backend systems, and the bits of software engineering that aren't always visible to the end user: APIs, databases, authentication, caching, and the decisions that hold an application together.

I've worked with JavaScript, TypeScript, PHP, Java, and SQL, building everything from small web applications to an AI-powered Dungeons & Dragons game.

I tend to learn best by actually working on something, running into problems, and figuring out how to solve them.

## Things I've built

### [myDnD — An AI Dungeon Master](https://github.com/sdsouza42/MyDnD_CHATGPT3_WebAPP_Expressjs)

What happens when you combine Dungeons & Dragons with an AI-powered Dungeon Master?

This was a team project where we built a browser-based D&D adventure game using Node.js, Express, MongoDB, and the OpenAI API.

Players can create characters, embark on adventures, engage in combat, and save their progress.

Being interested in tabletop RPGs myself, this is one of the more enjoyable applications I've worked on.

### [Course Management REST API](https://github.com/sdsouza42/laravel-course-management-api)

A backend project built with Laravel and MySQL.

It started as an exercise in REST API development and grew into an opportunity to explore application architecture, validation, database operations, caching, and automated testing.

Some of the more interesting parts include separating business logic into a service layer, managing cache invalidation, and setting up GitHub Actions to run tests against MySQL across multiple PHP versions.

### [CASA — Extreme Weather Preparedness](https://github.com/sdsouza42/Casa_js_App)

A collaborative web application designed to help people prepare their homes for extreme weather.

We built it using JavaScript, Firebase, and Bootstrap, with features involving weather information, preparation recommendations, and local services.

It was an opportunity to work on a practical problem while learning how to develop software as part of a team.
